Rules

Matte only: no gradients, chrome, glass blur, glow, textures, or clipped-text titles.One accent hue, plate rust. Fill #B8432F is for Start / Finish / Log set / ticks only. Numbers and selected effort use #D4785A on dark (the fill would fail 4.5:1 as text).Same accent fill in light and dark — the primary button does not flip polarity. Light accent text is the fill colour itself, and must not sit on raised (#EBE6DA, 4.34:1).Control outlines and card edges use Line, never a quieter decorative rule. Text ≥ 4.5:1, UI edges ≥ 3:1, type ≥ 13px. Gym targets 48–64px.Spacing is a 4/8px grid (4, 8, 16, 24, 32, 40, 48). Card padding 16px. Set rows 56px with a shared Previous / kg / Reps / tick template.The mobile rest timer is flush with the bottom of the screen; a 24px safe-area inset lives inside the bar.Production fonts must be self-hosted (offline PWA). Do not load Google Fonts from the network.
